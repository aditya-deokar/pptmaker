The Problem

Why another presentation tool?

  • Making presentations is slow and painful — blank slides, font picking, layout fiddling
  • Existing AI tools dump text onto slides — no layout awareness, no visual intelligence
  • No tool lets AI agents create & manage decks programmatically through MCP
  • Needed: layout-first generation + visual editor + MCP server — all in one app

Technical Decisions

Why I Built It This Way

  • LangGraph over one prompt — each agent does one thing well, easier to debug and extend
  • Layout before content — AI writes text that fits the slide shape, not the other way around
  • Streamable HTTP for MCP — no repo clone needed, just URL + API key
  • BYOK runtime — users bring Google/OpenAI/Groq keys, app routes through their preferred provider
  • Inngest for mobile design — background jobs with retry for long-running HTML frame generation
  • Clerk for auth — handles signup, login, sessions, webhooks out of the box
Challenges & Learnings

What Was Hard

  • MCP auth + session handling — initialize-first requirement tripped up different MCP clients
  • Structured JSON from LLMs — models don't always output valid JSON, needed validation + retries
  • Web ↔ MCP sync — both modify same data, both must go through same business logic
  • Real-time streaming — progress from 8 agents to frontend + persisted state for MCP polling
  • BYOK routing — 3 providers × user prefs × free-tier limits × MCP vs web sources
